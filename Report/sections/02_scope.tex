\section{Scope of Reproducibility}
\label{sec:scope}

We reproduce the main experimental sections of \citet{pearce2024bilinear}: Section 4 (Vision) demonstrating interpretable eigendecomposition on MNIST and Fashion-MNIST, and Section 5 (Language) discovering negation circuits in bilinear transformers using Sparse Autoencoder (SAE) analysis.

\subsection{Claims to Verify}

\paragraph{Section 4: Vision (Image Classification).}
The paper makes the following testable claims:
\textbf{V1 (Low-Rank Emergence):} Regularization induces low-rank structure in the bilinear interaction tensor (effective rank $\sim$20--40 with regularization vs.\ $\sim$150--200 without).
\textbf{V2 (Interpretable Eigenvectors):} Top eigenvectors correspond to interpretable digit-like stroke templates.
\textbf{V3 (Overfitting Without Regularization):} Without regularization, eigenspectrum is flat and eigenvectors show noise-like patterns.
\textbf{V4 (Regularization Roles):} Noise augmentation and weight decay have complementary effects.
\textbf{V5 (Cross-Seed Consistency):} Eigenvectors are consistent across seeds (cosine similarity 0.8--0.9).
\textbf{V6 (Adversarial Generation):} Adversarial perturbations can be constructed from eigendecomposition.

\paragraph{Section 5: Language (Negation Circuits).}
\textbf{L1 (SAE Feature Discovery):} SAEs reveal interpretable features for bilinear decomposition.
\textbf{L2 (Negation Features):} The model learns distinct features for ``not + negative'' and ``not + positive'' forming opposing directions.
\textbf{L3 (Low-Rank Interactions):} 69\% of SAE output features achieve $>$0.75 correlation with rank-2 approximation.
\textbf{L4 (Sparse Interaction Matrices):} Top interactions form interpretable AND-gate-like submatrices.
\textbf{L5 (Cross-Model Generalization):} Negation circuit structure appears across model sizes.

\subsection{Success Criteria}

\textbf{Vision:} Effective rank ratio (regularized/unregularized) $< 0.6$; top eigenvectors visually resemble digit templates; test accuracy within 2\% of paper ($\sim$95--98\%); results consistent across 5 seeds.

\textbf{Language:} AND-gate circuits show opposing eigenvalue signs; $>$50\% of features show $>$0.75 rank-2 correlation (relaxed from 69\%); interaction matrices show interpretable block structure.
