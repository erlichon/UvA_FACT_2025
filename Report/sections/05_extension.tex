\section{Extension Results}
\label{sec:extension}

We extend the original Bilinear MLP approach by proposing Canonical Polyadic (CP) decomposition as an architectural constraint that provides intrinsic interpretability during training, rather than discovering low-rank structure post-hoc via eigendecomposition.

\subsubsection{Background: Post-Hoc vs.\ Intrinsic Interpretability}

The original Bilinear MLP approach relies on \emph{post-hoc} analysis: after training, the interaction tensor is decomposed via eigendecomposition to reveal interpretable structure.
This post-hoc approach has a fundamental limitation: eigendecomposition enforces orthogonality, forcing features to be disjoint even when the underlying concepts naturally overlap.

Consider digit recognition: a vertical stroke and a horizontal stroke may co-occur in many digits (e.g., ``4'', ``7''), but orthogonality constraints force them into separate, mutually exclusive eigenvectors.
This creates \emph{entangled} features---mixed concepts that are artificially separated to satisfy mathematical constraints rather than representing natural visual decomposition.

In contrast, CP-decomposition provides \emph{intrinsic} interpretability by constraining the interaction tensor during training:
\begin{equation}
    B_{cij} = \sum_{r=1}^{R} \lambda_r A_{cr} B_{ir} C_{jr}
    \label{eq:cp_factorization}
\end{equation}
where $R$ is the chosen rank and $\lambda_r$ are learnable scaling factors.
This factorization allows non-orthogonal, \emph{disentangled} factors---each rank-1 component can represent an atomic concept (e.g., a specific stroke, loop, or edge pattern) without being forced into orthogonality.
Factors can naturally overlap, aligning better with how humans decompose visual patterns into components.

\subsubsection{CP Methods: Three Variants}

We implement three variants of CP decomposition, each providing different levels of constraint flexibility:

\textbf{Fixed CP:}
Hard structural constraint where the rank $R$ is constant throughout training.
No regularization is applied to the factors themselves beyond standard weight decay.
This provides guaranteed low-rank structure but may limit model capacity, resulting in lower accuracy.

\textbf{Lambda CP (Magnitude Regularization):}
Adds learnable scalar scales $\lambda_r$ per rank component with $L_1$ regularization on $\lambda$.
This encourages soft sparsity, allowing the model to downweight unnecessary ranks while keeping them active.
Provides a balance between structural constraint and flexibility.

\textbf{Gated CP (Sparsity Regularization):}
Adds probabilistic gates $z_r \sim \text{Bernoulli}(\sigma(\phi_r))$ per rank, where $\phi_r$ are learnable gate logits.
$L_0$ proxy regularization on the gates ($\sum_r \sigma(\phi_r)$) encourages explicit pruning of unnecessary ranks.
This is the most flexible approach, automatically finding the minimal set of active ranks without human specification.

All three variants are trained on MNIST with minimal regularization (weight decay $0.1$, no noise augmentation) across ranks $R \in \{8, 16, 32, 64, 128, 256, 784\}$ with 5 random seeds per configuration.

\textbf{Key findings:}

\begin{enumerate}
    \item \textbf{Three methods, three trade-offs:}
    \begin{itemize}
        \item \textbf{Fixed CP}: Achieves the lowest effective rank ($3.45 \pm 0.12$ at $R=64$) but sacrifices accuracy ($91.05\%$ vs.\ $97.49\%$ for dense, a $6.4\%$ drop).
        The hard structural constraint enforces extreme sparsity regardless of rank---effective rank remains $\sim$3.5 across all ranks tested.
        
        \item \textbf{Lambda \& Gated CP}: Maintain competitive accuracy ($93.0$--$93.8\%$) with moderate effective rank ($8.8$--$17.5$).
        At $R=64$, both achieve $\sim$93\% accuracy (only $4.4\%$ drop from dense) with effective rank $\sim$11.7.
        These methods successfully balance interpretability and performance.
    \end{itemize}
    
    \item \textbf{Rank scaling patterns differ by method:}
    \begin{itemize}
        \item \textbf{Fixed}: Effective rank remains consistently low ($\sim$3.4$--$3.7$) regardless of CP rank, demonstrating that the hard constraint enforces sparsity.
        
        \item \textbf{Lambda \& Gated}: Effective rank scales with CP rank ($R=32$: $\sim$9, $R=64$: $\sim$12, $R=128$: $\sim$15, $R=256$: $\sim$17), allowing the model to use more factors as capacity increases.
    \end{itemize}
    
    \item \textbf{Best configurations:}
    \begin{itemize}
        \item \textbf{Maximum interpretability}: Fixed $R=64$ ($91.05\%$, eff rank $3.45$)---$4.4\times$ lower effective rank than dense (WD).
        
        \item \textbf{Best accuracy-interpretability trade-off}: Lambda/Gated $R=128$ ($93.3$--$93.4\%$, eff rank $\sim$14.9)---competitive accuracy with explicit rank control.
        
        \item \textbf{Highest accuracy}: Lambda $R=256$ ($93.80\%$, eff rank $17.50$)---only $3.7\%$ accuracy gap from dense baseline.
    \end{itemize}
    
    \item \textbf{Self-organization to sparsity:}
    All CP variants demonstrate self-organization: at $R=64$, Fixed uses only $3.45$ effective rank (out of 64), while Lambda/Gated use $\sim$11.7 effective rank.
    This automatic sparsity suggests the model finds optimal feature sets without explicit regularization beyond the structural constraint.
\end{enumerate}

\textbf{CP Factors: Explicit Rank Control and Disentangled Representation}

CP decomposition provides several advantages for interpretability:

\begin{itemize}
    \item \textbf{Explicit rank control:} The factorization in Equation~\ref{eq:cp_factorization} directly constrains the interaction tensor to rank $R$, providing guaranteed interpretability bounds.
    Unlike dense models where low-rank structure emerges through regularization, CP enforces structure architecturally.
    
    \item \textbf{Non-orthogonal factors:} CP factors are not constrained to be orthogonal, allowing them to represent overlapping concepts naturally.
    For example, a ``vertical stroke'' factor and a ``horizontal stroke'' factor can both be active simultaneously without being forced into separate, mutually exclusive directions.
    
    \item \textbf{Localized, atomic patterns:} The rank-1 structure of each CP component encourages factors to represent localized patterns---specific strokes, loops, edges, and curves.
    Each factor can represent a disentangled concept with potential semantic meaning, such as ``vertical stroke in the middle'', ``top-right curve'', or ``bottom horizontal line''.
    
    \item \textbf{Automatic feature selection:} The quantitative results demonstrate that CP models self-organize to use only a subset of available ranks (e.g., $3.45$ effective rank from $64$ possible for Fixed, $11.7$ for Lambda/Gated).
    This automatic sparsity suggests the model finds optimal feature sets without explicit regularization.
\end{itemize}

The visual patterns observed in CP factors (Figures~\ref{fig:factors_vs_vecs} and~\ref{fig:cp_eigenvectors_top2}) suggest they may represent more localized, atomic concepts compared to the holistic templates that emerge from eigendecomposition.
The top eigenvectors shown in Figure~\ref{fig:cp_eigenvectors_top2} demonstrate class-specific patterns that appear to capture distinct visual components for each digit class.
However, further analysis is needed to confirm whether this translates to improved interpretability in practice.

The eigenvalue spectrum (Figure~\ref{fig:cp_eigenspectrum}) and coverage analysis (Figure~\ref{fig:cp_topk_coverage}) together provide comprehensive evidence for the interpretability advantage of CP decomposition.
The spectrum reveals how information is distributed, while the coverage analysis quantifies how many factors need to be examined to understand the model's behavior.
For Fixed CP, the top-5 factors capture the majority of information, making it highly transparent despite the accuracy trade-off.
This quantitative evidence supports the claim that CP decomposition provides superior interpretability through explicit rank control.

\subsubsection{Conclusion: CP as a Complexity Throttle}

CP decomposition serves as a ``complexity throttle,'' offering guaranteed low-rank structure with explicit rank control.
The three variants provide different trade-offs:

\begin{itemize}
    \item \textbf{Fixed CP}: Guarantees extreme sparsity (effective rank $\sim$3.5) but sacrifices accuracy ($\sim$6.4\% drop).
    Best for applications requiring guaranteed interpretability bounds.
    
    \item \textbf{Lambda \& Gated CP}: Maintain competitive accuracy ($\sim$93\%$, only $4.4\%$ drop) while providing explicit rank control.
    Best for applications requiring both interpretability and performance.
    
    \item \textbf{All variants}: Demonstrate self-organization to sparsity, automatically finding optimal feature sets without explicit regularization.
\end{itemize}

The accuracy cost varies by method: Fixed CP incurs a $6.4\%$ drop, while Lambda/Gated CP incur only a $4.4\%$ drop at $R=64$.
This cost may be acceptable when:

\begin{itemize}
    \item Interpretability guarantees are required (regulatory compliance, safety-critical systems)
    \item Explicit rank bounds are needed for computational efficiency
    \item Noise augmentation is undesirable or impractical
    \item Factors need semantic meaning for explainable AI applications
\end{itemize}

CP decomposition provides a promising approach for building transparent, interpretable models with explicit architectural constraints, offering a middle ground between dense models (high accuracy, emergent interpretability) and highly constrained models (guaranteed interpretability, lower accuracy).
