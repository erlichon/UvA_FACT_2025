\section{Reproduction Results}
\label{sec:reproduction}

This section presents our reproduction of the main experiments from \citet{pearce2024bilinear}: Section 4 (Vision) on MNIST/Fashion-MNIST and Section 5 (Language) on bilinear transformers.

\subsection{Vision Results (Paper Section 4)}
\label{sec:vision_results}

We trained bilinear MLPs on MNIST and Fashion-MNIST under four regularization configurations across 5 random seeds each.

\subsubsection{Main Result: Regularization Induces Low-Rank Structure (Claim V1)}
The paper's central claim is that regularization induces low-rank structure in the bilinear interaction tensor.
Figure~\ref{fig:ablation_combined} confirms this through our ablation experiments.
Weight decay is the primary driver of low-rank structure, achieving the lowest effective rank (15.5 vs.\ 21.4 for full regularization), while noise augmentation increases effective rank but improves accuracy.
The effective rank ratio (15.5/38.5 $\approx$ 0.40) meets the paper's $<0.5$ criterion.
Eigenvalue distributions reveal sharp spectral decay with regularization (Figure~\ref{fig:eigenspectrum}, Appendix~\ref{app:vision_additional}), concentrating variance in 10--20 eigenvectors.
Top eigenvectors are interpretable digit-like patterns under regularization, while unregularized models show diffuse, noise-like patterns (Figures~\ref{fig:eigenvectors_noreg} and~\ref{fig:eigenvectors_reg}, Appendix~\ref{app:vision_additional}).

\subsubsection{Model Size and Truncation (Claim V5)}
\label{sec:model_size_truncation}

Top eigenvectors are highly consistent across random seeds, especially for larger models.

\subsection{Language Results (Paper Section 5)}
\label{sec:language_results}
We reproduce negation circuit discovery using pretrained bilinear transformers and SAEs from HuggingFace.\footnote{SAE repositories: \texttt{tdooms/fw-medium-scope}, \texttt{tdooms/ts-medium-scope}, \texttt{tdooms/fw-small-scope}.}
Our protocol: pass tokenized batches through each model, record \texttt{mlp\_in}/\texttt{mlp\_out} activations, encode with output SAE, and compare sparse features to low-rank predictions from interaction eigenpairs.
We analyze all \emph{active features} (positive activation for $\geq$1 token) using Pearson correlation.
\textbf{SAE availability gap:} \texttt{ts-medium-scope} lacks \texttt{mlp-in} SAEs for layer 4, so Figure~8's ts-tiny setup cannot be reproduced.
We use \texttt{fw-medium} (layer 7, expansion 8) which has both SAE types.

\subsubsection{Negation Circuit Discovery (Paper Figure 8)}
The paper claims bilinear layers enable circuit discovery via eigendecomposition.
For output feature $f$, the interaction matrix $Q_f$ captures how input feature pairs contribute to $f$'s activation: $z^{\text{out}}_f \approx (\mathbf{z}^{\text{in}})^\top Q_f \mathbf{z}^{\text{in}}$.
Eigendecomposing $Q_f$ reveals dominant input directions.
Figure~\ref{fig:negation_circuit} shows this for negation features in fw-medium:
\textbf{(A) Interaction submatrix}: $Q_f$ restricted to top-15 input features, grouped by cluster.
Red blocks indicate positive interactions (features that co-activate $f$), blue indicates negative.
\textbf{(B) Eigenvector projections}: Input features projected onto top eigenvectors.
Neg./Pos.\ sentiment features cluster separately; arrows show ``good''/``bad'' unembed directions and ``not'' input direction.
The black dot marks where the output feature lies-at the intersection of negation and sentiment.
This reveals the AND-gate circuit: \emph{negation $\otimes$ sentiment $\to$ negated-sentiment}.

\textbf{Feature selection and interpretation:}
Following the tutorial methodology, we select output features by ranking all 8,192 features by their top eigenvalue magnitude-a heuristic for identifying features with strong interaction structure.
Features 3834 and 751 emerge as the top two, with weakly negative cosine similarity ($-0.16$) between their SAE decoder directions-what the tutorial calls a ``somewhat linear subspace.''
Semantic interpretation comes from inspecting top-activating tokens: feature 3834 fires on negated positive contexts (``no losses'', ``not lost''), while feature 751 fires on negated negative contexts (``not harmless'', ``doesn't go away'').
These are \emph{semantic} opposites (not-good vs.\ not-bad), though not geometrically opposing ($-0.16$ is closer to orthogonal than anti-parallel).
As additional validation, we test the circuit on FineWeb-16k (the model's training distribution): correlations remain strong (0.91/0.82 vs.\ 0.93/0.83 on TinyStories), demonstrating robustness to distribution shift (Appendix~\ref{app:figure8_investigation}).

\subsubsection{Low-Rank Correlation Analysis (Paper Figure 9)}
The paper claims most features achieve $>$0.75 rank-2 correlation.
We interpret ``most features'' as a median threshold ($>$50\% of features achieving $>$0.75 correlation).
For each token, we record MLP input activations and encode them with the output SAE ($k$=30 TopK sparsity, matching the paper) to obtain sparse feature activations.
For each active feature $f$ (where $n$ denotes the number of features with at least one non-zero activation), we eigendecompose its interaction matrix $Q_f$ and compute Pearson correlation between true and low-rank predicted activations across all tokens where the feature is active.
All models processed $\sim$1.57M tokens: ts-medium used TinyStories validation~\citep{eldan2023tinystories}, while fw-small and fw-medium used FineWeb-Edu~\citep{penedo2024fineweb}.

\subsubsection{Root Cause Analysis}
The paper notes correlation improves with SAE training time (Appendix H).
We confirm this using fw-medium layer 12 checkpoints v0--v4 (Figure~\ref{fig:sae_training_effect}, Appendix~\ref{app:language_results}): rank-2 correlation improves from 0.15 to 0.39 with longer training, consistent with the paper's acknowledgment that ``correlation drastically improves with longer SAE training.''

\textbf{Model training duration hypothesis:} We observe a correlation between training compute (tokens/parameter) and low-rank behavior: ts-medium (83 tokens/param, $n$=2048, 32\%), fw-medium (95 tokens/param, $n$=5688, 45\%), and fw-small (198 tokens/param, $n$=3072, 65\%).
Under the median interpretation ($>$50\% threshold), only fw-small reproduces the claim, while ts-medium and fw-medium fall short.
Since more training tokens corresponds to longer training time, this parallels Figure~\ref{fig:sae_training_effect}: just as undertrained SAEs fail to capture low-rank structure, undertrained models (low tokens/param) may not develop the structured interactions that exhibit low-rank approximability.
Figure~\ref{fig:correlation_analysis}(c) visually confirms this: only $\sim$3 of 9 randomly sampled features show strong true-vs-predicted correlation.

\textbf{SAE artifact limitation:} The paper uses 4x expansion SAEs for all models.
However, for fw-medium at 2/3 depth (layer 10--11), only 8x expansion SAEs are publicly available-4x is only available at layers 6 and 12.
With 8x expansion (8192 total features, of which 5688 are active), more sparse/specialized features exist, potentially lowering average correlation.
This artifact gap prevents exact reproduction of the paper's fw-medium configuration.
