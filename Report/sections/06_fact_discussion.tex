\section{Discussion}
\label{sec:discussion}

\subsection{What was Easy}
\label{sec:easy}

\textbf{Vision experiments were straightforward to reproduce.}
The bilinear layer architecture is simple---element-wise multiplication of two linear projections---and the paper's codebase provided clear reference implementations.
MNIST's small scale ($\sim$3 minutes per training run on GPU) enabled rapid iteration.
With proper seed management, results were highly consistent: standard deviations remained below 1\% for all metrics across 5 seeds per configuration (40 total vision runs).

\textbf{The eigendecomposition methodology is robust and computationally efficient.}
Computing eigenvalues and eigenvectors for $784 \times 784$ interaction matrices completes in seconds on CPU.
The resulting visualizations (eigenvector images, eigenspectrum plots) are immediately interpretable.

\textbf{Paper code availability accelerated development.}
The original codebase (\texttt{github.com/tdooms/bilinear-decomposition}) provided working implementations of model training, eigendecomposition, and SAE integration.
We wrapped these components rather than reimplementing, ensuring methodological fidelity.

\subsection{What was Difficult}
\label{sec:difficult}

\textbf{Hyperparameter disambiguation required careful reading.}
The paper's code defaults (noise std $= 0.4$, weight decay $= 0.5$) differ from Appendix G.1's reported values (noise std $= 0.5$, weight decay $= 1.0$).
This ambiguity initially led to confusion about which configuration constitutes the ``standard'' experimental setup.
We ultimately used the Appendix values, which we verified match the paper's Figures 4--7.

\textbf{SAE availability limited language reproduction.}
The paper's Figure 8 uses \texttt{ts-medium} (TinyStories model, 6 layers, 29M params), but the HuggingFace SAE repository for this model lacks \texttt{mlp-in} SAEs---only \texttt{mlp-out}, \texttt{resid-mid}, and \texttt{resid-pre} positions are available.
The paper's interaction matrix analysis requires \emph{both} input and output SAEs.
We pivoted to \texttt{fw-medium} (FineWeb-EDU, 16 layers, 335M params), which has complete SAE coverage but is trained on educational text rather than children's stories, producing different circuit structure.

\textbf{Memory constraints required algorithmic modifications.}
The na\"ive interaction matrix computation for language models involves \texttt{einsum} operations with $O(n_{\text{features}}^2)$ memory.
At expansion ratio 8$\times$ with $d_{\text{model}} = 1024$, this produces 8192 features and requires $>$100GB RAM.
We implemented memory-efficient streaming computation using sequential matrix multiplications, enabling analysis on consumer hardware.

\textbf{Tracing the low-rank discrepancy required systematic investigation.}
Our initial correlation results (mean 0.37--0.55) appeared to contradict the paper's claim (69\% $>$ 0.75).
Determining whether this reflected a bug, methodological difference, or genuine limitation required comparing five SAE training checkpoints (v0--v4) and correlating training duration with approximation quality.
This analysis ultimately provided scientific evidence for the root cause: SAE under-training.

\textbf{Efficiency implications of low-rank structure.}
Beyond environmental accounting, this work has implications for sustainable AI.
CP-decomposition reduces parameter count from $O(d_{\text{hidden}} \times d_{\text{in}}^2)$ to $O(R \times d_{\text{in}})$, enabling:
(1) smaller memory footprint during training and inference,
(2) faster matrix operations due to factored structure, and
(3) reduced energy consumption at deployment scale.
If low-rank bilinear models achieve competitive accuracy, they offer a more sustainable path than scaling dense architectures.

\subsection{Connection to FACT-AI Topics}
\label{sec:fact}

This work directly addresses \textbf{Transparency} (FACT-AI Topic 1.4).

\textbf{Weight-based vs. Post-hoc Interpretability.}
Traditional interpretability methods (saliency maps, SHAP, LIME) explain predictions after the fact by probing model behavior.
Bilinear MLPs offer intrinsic transparency: the interaction tensor's eigenvectors \emph{are} the model's learned features.
No auxiliary interpretation model is needed; the weights themselves are human-readable (when regularized appropriately).

\textbf{Reproducibility as Transparency.}
Our partial reproduction of the language results highlights an underappreciated transparency dimension: \emph{reproducibility}.
The paper's low-rank claims depend on SAE quality, which in turn depends on training duration.
Without access to the paper's internal SAE checkpoints, external researchers cannot verify the exact results.
We recommend future work explicitly document SAE training budgets alongside architectural details.

\textbf{Trade-offs between Accuracy and Interpretability.}
Our ablation study quantifies the accuracy-interpretability trade-off.
Weight decay reduces effective rank from 38.5 to 21.4 (a $1.8\times$ improvement in interpretability) at the cost of $<$1\% accuracy.
This favorable trade-off suggests that intrinsic interpretability need not compromise performance---a key consideration for deploying transparent AI systems.

\textbf{Implications for AI Accountability.}
If eigenvectors reliably capture decision-making features, they provide a foundation for:
\begin{itemize}
    \item \textbf{Auditing}: Inspecting eigenvectors for unintended biases (e.g., spurious correlations with protected attributes).
    \item \textbf{Explanation}: Decomposing predictions into contributions from interpretable features.
    \item \textbf{Debugging}: Identifying failure modes by examining low-ranked or adversarial eigenvectors.
\end{itemize}
Our successful reproduction of vision results (interpretable digit eigenvectors) demonstrates this potential; extending to language requires better-trained SAEs.

\subsection{Communication with Original Authors}
\label{sec:authors}

We did not contact the original authors during this reproduction.
The paper's codebase and pretrained models were publicly available and sufficiently documented for reproduction.
Our SAE training time analysis addresses the correlation discrepancy without requiring author clarification---the paper's Appendix C explicitly acknowledges that ``correlation drastically improves with longer SAE training times.''

\section{Conclusion}
\label{sec:conclusion}
%==============================================================================

We reproduced both main experimental sections from \citet{pearce2024bilinear} and report mixed results.

\textbf{Vision (Section 4): Fully Reproduced.}
\begin{enumerate}
    \item Weight decay induces low-rank structure: effective rank drops from 38.5 (no regularization) to 21.4 (weight decay only), confirming the paper's central claim.
    \item Eigenvectors under noise augmentation show interpretable digit patterns, while unregularized eigenvectors appear diffuse and uninterpretable.
    \item Accuracy remains high (97--98\%) regardless of regularization, demonstrating minimal trade-off.
    \item Results are robust across 5 seeds and generalize to Fashion-MNIST.
\end{enumerate}

\textbf{Language (Section 5): Partially Reproduced.}
\begin{enumerate}
    \item \textbf{Negation circuit discovery: Confirmed.}
    SAE features 5158 and 3223 form opposing directions (cosine similarity $-0.16$), implementing sentiment negation as claimed.
    
    \item \textbf{Low-rank interaction structure: Not confirmed.}
    The paper claims 69\% of features have $>$0.75 rank-2 correlation.
    We find mean correlations of 0.37--0.55 across three models using publicly available SAEs.
    
    \item \textbf{Root cause identified: SAE training time.}
    Comparing five SAE training checkpoints, we observe $2.5\times$ improvement in rank-2 correlation with longer training (0.15 $\to$ 0.39).
    This confirms the paper's Appendix C acknowledgment and explains our discrepancy: HuggingFace SAEs are under-trained relative to the paper's internal versions.
\end{enumerate}

\textbf{Key Insight.}
The bilinear decomposition methodology is sound and reproducible.
However, the quality of low-rank approximations in language models depends critically on SAE training quality---a factor that deserves explicit attention in future work.
Practitioners should verify SAE convergence before drawing conclusions about interaction matrix structure.

\textbf{Limitations.}
\begin{itemize}
    \item Eigenvector interpretability is assessed qualitatively; quantitative metrics would strengthen claims.
    \item We could not reproduce Figure 8 with the paper's exact model (\texttt{ts-medium}) due to missing \texttt{mlp-in} SAEs on HuggingFace.
    \item CP-decomposition extension results are preliminary (single-seed); multi-seed runs would provide statistical confidence.
\end{itemize}

\textbf{Future Work.}
\begin{itemize}
    \item Train SAEs for longer to test whether the paper's 69\% threshold is achievable.
    \item Develop quantitative metrics for eigenvector interpretability.
    \item Extend bilinear decomposition to larger vision models (ViTs) and verify scalability.
    \item Complete CP-decomposition analysis with multi-seed runs and Pareto frontier visualization.
\end{itemize}
