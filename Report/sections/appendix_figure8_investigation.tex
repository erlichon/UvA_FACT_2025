\section{Sentiment Negation Circuit Investigation}
\label{app:figure8_investigation}

This appendix presents our detailed investigation of AND-gate circuits in the bilinear transformer fw-medium (16 layers, 335M parameters, trained on FineWeb-EDU).
The paper's Figure 8 demonstrates a sentiment negation circuit using feature 3834 from the fw-medium model.
We conducted a comprehensive search to understand the prevalence and strength of such circuits.

\subsection{Methodology}

\subsubsection{AND-gate Circuit Definition}
An AND-gate circuit is characterized by an output SAE feature whose activation depends on the \emph{conjunction} of inputs from two semantically distinct clusters.
Mathematically, for output feature $c$, the activation is:
\begin{equation}
z_c(x) = x^\top Q_c x \approx \lambda_1 (v_1^\top x)^2 + \lambda_2 (v_2^\top x)^2
\end{equation}
where $Q_c$ is the interaction matrix, and $v_1, v_2$ are the dominant eigenvectors.

Strong AND-gate behavior requires:
\begin{enumerate}
    \item \textbf{Dominant rank-2 structure}: The top two eigenvalues capture most of the interaction.
    \item \textbf{Opposing eigenvalue signs}: $\lambda_1$ and $\lambda_2$ have opposite signs, creating cancellation when only one cluster is present.
    \item \textbf{Clear cluster separation}: Input features project distinctly onto $v_1$ and $v_2$.
\end{enumerate}

\subsubsection{AND-score Metric}
We define an ``AND-score'' to quantify circuit strength:
\begin{equation}
\text{AND-score} = \frac{|\lambda_1|}{|\lambda_1| + |\lambda_2|} \cdot \mathbf{1}[\text{sign}(\lambda_1) \neq \text{sign}(\lambda_2)]
\end{equation}
Higher scores indicate stronger AND-gate behavior (score $\in [0, 1]$).

\subsubsection{Search Procedure}
We analyzed all 8,192 output features in fw-medium layer 7:
\begin{enumerate}
    \item Computed the interaction matrix $Q_c$ for each feature $c$
    \item Performed eigendecomposition: $Q_c = \sum_j \lambda_j v_j v_j^\top$
    \item Computed AND-score from top eigenvalues
    \item Ranked features by AND-score
    \item Analyzed top circuits for semantic interpretation
\end{enumerate}

\subsection{Results: Feature 3834 vs Feature 751}

\subsubsection{Tutorial Feature 3834}
Feature 3834 (used in the paper's tutorial) encodes ``not-good'' contexts:
\begin{itemize}
    \item \textbf{Activating contexts}: ``not lost'', ``no interference'', negated positive phrases
    \item \textbf{AND-score}: Weak (diffuse eigenvalue spectrum)
    \item \textbf{Cluster structure}: Less distinct separation between input clusters
\end{itemize}

\subsubsection{Best Circuit: Feature 751}
Our search identified feature 751 as having the strongest AND-gate structure:
\begin{itemize}
    \item \textbf{AND-score}: 0.963 (highest among all 8,192 features)
    \item \textbf{Top eigenvalue}: $\lambda_1 = -0.463$ (negative)
    \item \textbf{Second eigenvalue}: $\lambda_2 = +0.179$ (positive)
    \item \textbf{Eigenvalue ratio}: $|\lambda_1|/|\lambda_2| = 2.59$
    \item \textbf{Cluster sizes}: 3 features in positive cluster, 12 in negative cluster
\end{itemize}

\subsection{Interpretation}

\subsubsection{Why Feature 751 is Stronger}
Feature 751 exhibits superior AND-gate properties because:
\begin{enumerate}
    \item \textbf{Spectral concentration}: 85\% of variance captured by top 2 eigenvalues
    \item \textbf{Sign opposition}: $\lambda_1 < 0$ and $\lambda_2 > 0$ creates effective cancellation
    \item \textbf{Clean clustering}: Input features separate clearly along $v_1$
\end{enumerate}

\subsubsection{Semantic Content}
The input clusters for feature 751 contain:
\begin{itemize}
    \item \textbf{Positive cluster} (3 features): Structural/contextual markers
    \item \textbf{Negative cluster} (12 features): Content-specific features
\end{itemize}

Note: Unlike ts-medium (trained on TinyStories), fw-medium (trained on FineWeb-EDU educational text) does not show clean sentiment-based clustering.
The clusters reflect domain-specific patterns in educational/scientific writing rather than simple positive/negative sentiment.

\subsection{Implications}

\subsubsection{Circuit Discovery Requires Systematic Search}
The tutorial feature (3834) is a weaker example than what exists in the model.
Comprehensive search revealed that feature 751 has 43\% higher AND-score.
This suggests practitioners should search across features rather than manually inspecting individual examples.

\subsubsection{Model Domain Affects Interpretability}
The fw-medium model (educational text) shows different semantic clustering than ts-medium (children's stories).
AND-gate circuits exist in both, but their semantic interpretation differs.
This has implications for transferring interpretability findings across model families.
