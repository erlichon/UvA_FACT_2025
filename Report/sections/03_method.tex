\section{Methodology}
\label{sec:methodology}

\subsection{Bilinear Layer Architecture}

The bilinear layer replaces standard nonlinearities with element-wise multiplication:
\begin{equation}
    \mathbf{y} = (\mathbf{W}_l \mathbf{x}) \odot (\mathbf{W}_r \mathbf{x})
    \label{eq:bilinear}
\end{equation}
where $\mathbf{W}_l, \mathbf{W}_r \in \mathbb{R}^{d_{\text{hidden}} \times d_{\text{in}}}$ are learnable weight matrices and $\odot$ denotes the Hadamard product.
Unlike standard MLPs with fixed nonlinearities, bilinear layers compute \emph{input-dependent} gating: the left projection gates the right projection.
This creates a quadratic dependence on the input expressible as a third-order interaction tensor:
\begin{equation}
    y_c = \sum_{i,j} B_{cij} x_i x_j
    \label{eq:tensor}
\end{equation}
where $B_{cij} = \sum_h W_{\text{head},ch} (W_l)_{hi} (W_r)_{hj}$ and $W_{\text{head}} \in \mathbb{R}^{d_{\text{out}} \times d_{\text{hidden}}}$ is the output projection.

\subsection{Eigendecomposition for Interpretability}

For each output class $c$, we extract the $d_{\text{in}} \times d_{\text{in}}$ interaction matrix $B_c$ and symmetrize it:
\begin{equation}
    B_c^{\text{sym}} = \frac{1}{2}(B_c + B_c^\top)
\end{equation}
Symmetrization removes arbitrary asymmetry from the $W_l / W_r$ factorization while preserving the quadratic form $\mathbf{x}^\top B_c \mathbf{x}$.
The symmetric matrix admits eigendecomposition:
\begin{equation}
    B_c^{\text{sym}} = \sum_{r=1}^{d_{\text{in}}} \lambda_r^{(c)} \mathbf{v}_r^{(c)} (\mathbf{v}_r^{(c)})^\top
\end{equation}
where eigenvectors $\mathbf{v}_r^{(c)} \in \mathbb{R}^{d_{\text{in}}}$ represent interpretable input directions.
If the eigenspectrum is \emph{low-rank} (few dominant eigenvalues), the model's decision depends on only a few input directions that can be directly inspected.

We quantify spectral concentration using effective rank~\citep{roy2007effective}:
\begin{equation}
    \text{EffRank}(\boldsymbol{\lambda}) = \left( \frac{\|\boldsymbol{\lambda}\|_1}{\|\boldsymbol{\lambda}\|_2} \right)^2 = \frac{\left(\sum_i |\lambda_i|\right)^2}{\sum_i \lambda_i^2}
    \label{eq:effrank}
\end{equation}
where $\boldsymbol{\lambda} = (\lambda_1, \ldots, \lambda_d)$ is the vector of eigenvalues from the decomposition.
This scale-invariant measure ranges from 1 (single dominant eigenvalue) to $d$ (uniform spectrum).

\subsection{Language Model Analysis with SAEs}
\label{sec:language_method}

For language experiments, we combine bilinear decomposition with Sparse Autoencoders (SAEs)~\citep{bricken2023monosemanticity} to discover interpretable circuits.
Bilinear transformers use the same gated structure (Eq.~\ref{eq:bilinear}) in their MLP layers, enabling decomposition of how input features interact to produce outputs.

\textbf{Input/Output Decomposition.}
We position SAEs at both MLP input (\texttt{mlp-in}) and output (\texttt{mlp-out}).
Let $\mathbf{z}^{\text{in}} \in \mathbb{R}^{d_{\text{sae}}}$ be the sparse input feature activations and $z^{\text{out}}_f$ be the activation of output feature $f$.
The bilinear structure implies $z^{\text{out}}_f \approx (\mathbf{z}^{\text{in}})^\top Q_f \, \mathbf{z}^{\text{in}}$, where $Q_f$ is the interaction matrix for feature $f$.
We eigendecompose $Q_f$ to find dominant input directions: if rank-2 captures most variance, the output feature depends on just two input directions---revealing interpretable circuits (e.g., ``negation $\otimes$ sentiment $\to$ negated-sentiment'').

We use pretrained SAEs from \citet{pearce2024bilinear} with expansion 4--8$\times$ and TopK sparsity ($k=30$).
Low-rank quality is measured via Pearson correlation between true activations and rank-$k$ predictions.
The paper claims 69\% of features achieve $>$0.75 correlation at rank-2.

\subsection{Experimental Setup}

For vision experiments, we train bilinear MLPs on MNIST~\citep{lecun1998gradient} and Fashion-MNIST~\citep{xiao2017fashion} under four regularization configurations (Table~\ref{tab:reg_configs}), each with 5 random seeds (42--46).
Architecture: $d_{\text{hidden}} = 256$, 100 epochs, batch size 2048, AdamW optimizer with lr $10^{-3}$ and cosine annealing.
For language experiments, we analyze pretrained bilinear transformers (Table~\ref{tab:language_configs}, Appendix~\ref{app:language_results}).
Due to SAE availability constraints (see Section~\ref{sec:discussion}), our primary model is \texttt{fw-medium} rather than the paper's \texttt{ts-medium}.
We implemented a memory-efficient streaming algorithm for eigendecomposition to handle large interaction tensors.
